# Microstructure Evolution
## Nucleation and growth
A major component of the PhD work was the development of stochastic and mechanistic approaches for simulating **nucleation-growth kinetics in discretized spatial domains**.
This led to **EvoSim**, a generic simulation algorithm and cross-platform GUI application implemented using C++, Qt and Python.
```text
Nucleation
    ↓
Growth
    ↓
Interaction / impingement
    ↓
Evolving spatial structure
```
## Physics-informed modeling
Related modelling experience includes dynamic recrystallization, grain-size relationships, thermo-mechanical processing, phase transformation kinetics and microstructure evolution.
## Processing → structure → response
```text
Processing

Microstructure

Microstructural evolution

```
